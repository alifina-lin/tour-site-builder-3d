怎麼請 AI 把原始資料整理成六張表？

  1. 打開任何一個你慣用的 AI（Gemini、Copilot、ChatGPT、Claude 都可以）。
  2. 複製下面的指令，貼給 AI，再把你的原始資料貼上去，或附上檔案。
    3. 

  3. AI 會先用 200 字內說明它的整理邏輯、假設的讀者，以及哪些格子是推論的。請你核對，用口語說要改哪裡（例如「第二個分類改成……」）。
    4. 

  4. 你說「好」之後，請 AI「把完整的六張表放進同一個程式碼區塊」，按程式碼區塊右上角的複製鈕。
    5. 

  5. 貼到這個頁面左邊的格子，右邊就會長出預覽，左邊也會用白話告訴你哪裡還要處理。
    6. 



小提醒：原始資料送到哪個 AI，就依那個 AI 的規範處理，個人資料請先去除。數字與案例請再對照原文確認一次，AI 沒把握的格子會被它列在說明裡。




關於這個小工具


這個小工具由電算中心行政諮詢組 Ali 與 Claude Code 協作完成，協助大家「把文字轉譯成一座可以走進去的小世界」。


怎麼做的


場景以 Three.js 繪製低多邊形的 3D 微縮群島：每個主題是一座六角形小島，島上有建築、道路、走動的人與小動物，還有隨時間切換的日夜與海面。你整理好的六張表會被轉成一份資料，引擎讀了就畫出整座島，最後打包成單一 HTML 檔，單機瀏覽或自行上傳到伺服器皆可。
