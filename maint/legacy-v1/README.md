# 舊版（v1）引擎原始碼

這裡是六角群島第一版的可讀原始碼（`scene_islands.js`、`engine.src.html`）與打包工具（`bundle_engine.py`）。

**它和現在使用的引擎不同步。** 現在的 `assets/engine.html` 是 Ali 調整後的 v3（節奏調整、日夜主題、合成音效），是已經打包好的單一檔案，可讀的原始碼不在這個資料夾。若執行 `bundle_engine.py`，會用舊版覆蓋掉 v3，請不要這麼做，除非你就是要退回舊版。

要修改 v3，請用 Ali 保存 v3 的原始專案；`engine.v1.html` 是 v1 打包檔，僅供比對。
