# 新增場景範本

引擎把「場景」和「演出」分開：運鏡、六段演出、右側面板與手機抽屜、資訊卡、鍵盤、收束畫面是共用的；每個場景範本只負責「畫出世界」。目前有「小島」（`islands`，舊代號 `town` 也指向它）、「大樓」（`tower`）與「市集」（`market`）。市集的可讀原始碼在 `maint/engine-source/market-template.js`，示範了每幀更新的人潮與沿走道的鏡頭動線。大樓的可讀原始碼在 `maint/engine-source/tower-template.js`，是目前最完整的範例（含自己的日夜模組 `tower-theme.js` 與樣式 `tower.css`）。

## 範本長什麼樣子

在引擎原始碼裡新增（v1 範例：`maint/legacy-v1/scene_islands.js`）：

```js
SCENE_TEMPLATES.railway = { name: '環島鐵路', build({THREE, scene, data, colorOf}) {
  // 回傳：
  return {
    anchors,        // { 實體代號: THREE.Object3D }  標籤與鏡頭對準的點
    pickables,      // THREE.Object3D[]  可點擊的 mesh，每個要設 userData.eid = 實體代號
    overviewPose,   // { pos: Vector3, target: Vector3 }  全景鏡位
    focusPose(eid), // { pos, target }  聚焦到某個實體時的鏡位
    setFocus(eid),  // eid 或 null：亮起／熄滅
    update(t, dt, camera) // 每幀呼叫，放動態元素
  };
}};
```

使用者在 xlsx 的 `範本` 欄填 `railway` 就會使用它。

## 資料

`data` 是 xlsx 轉出的內容：`site`、`categories`、`steps`、`entities`、`dynamics`、`sources`（欄位對照見 `scripts/kit.py` 的 `to_data`）。`colorOf(類別代號)` 取得識別色。

> **目前的狀況：** 引擎是已打包的 `assets/engine.html`；`maint/engine-source/` 有拆出來的可讀版本。

## 加一個範本要改的地方（以大樓為例）

1. 在 `var dM = Hc[...]` 之前加上 `Hc.新代號 = { name, build }`，並加一行中文別名（例：`Hc["大樓"] = Hc.tower`）。
2. 引擎會在 `<body>` 加上 `tpl-代號` 的 class，`window.__tour.tpl` 也會是代號。範本專用的樣式一律寫在 `body.tpl-代號` 底下；範本專用的模組開頭先檢查這個 class，不是自己就直接結束（小島的日夜裝飾層 `theme-decor` 也是這樣）。
3. `build()` 除了上面的必要欄位，還可以回傳：`islandPicks`（點了會呼叫 `focusIsland(i)` 的 mesh，`userData.isl = 分類序號`）、`islandPose(i)`（聚焦某個分類的鏡位）、`R`（鏡頭最遠距離的基準）、`noCatLabels: true`（不要小島那種「擠的島只顯示分類名」標籤）、`setTheme(0~1)`（給日夜模組呼叫）。
4. 音效的環境音可依 `document.body.classList.contains("tpl-代號")` 換聲音（大樓用空調底噪，不放鳥鳴蟲鳴）。
5. 小幫手頁面右上的版型按鈕在 `maint/builder.src.html`（`TPL_NAME`、`tplOf`、`.tplbar`），加一顆按鈕並更新 `tplOf`。
6. 跑 `make_builder.py`、`test_engine.py`、`test_builder.py`，並在 `test_engine.py` 補上新範本的檢查。

## 重新打包（維護者）

```bash
cd maint
python3 make_builder.py ..          # 引擎更新後，重組小幫手頁面
python3 test_builder.py .. out` 與 `python3 test_engine.py ..      # 小幫手頁面測試
```

規則：不載入外部資源（圖片、字型、程式庫、追蹤碼）、文字一律當純文字處理（用 `textContent` 或先跳脫）、不使用瀏覽器儲存空間、尊重 `prefers-reduced-motion`、手機與電腦都能用。新增後用範例資料跑 `kit.py shoot ... --play`，確認「主控台錯誤：無」「外連請求：無」，並親眼看截圖。

引擎裡有兩個以上範本時，SKILL.md 階段 1 要讓使用者選。
