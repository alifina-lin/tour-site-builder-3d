# 微縮世界式資訊網站：設計規格（精簡版）

這套方法源自「LL家鐵路環島大富翁・3D 遊戲島」的設計思考。地圖、骰子、火車只是那個作品的隱喻；要沿用的是思考方式和美感。完整原文在使用者的 Google 雲端硬碟「3D遊戲化資訊網站_規格與設計風格」。

## 核心：全貌靠畫面，順序靠演出，深度靠點開

1. 先給整體畫面（一座島、一個小鎮、一棟大樓剖面），讓人一眼看懂「由哪些部分組成」。
2. 再一步一步帶著走，每一步只講一件事。
3. 想深入的人隨時點開細節。

## 五個原則

1. **選隱喻世界，不是一堆區塊。** 服務介紹→小鎮／島（服務＝建築、對象＝人、關係＝道路）；願景策略→通往未來的路；年度成果→四季地景；申辦流程→生產線／旅程；部門分工→大樓剖面。判斷標準：看到全景能說出「這件事由這幾塊組成」。
2. **一次只動一處。** 每步依序：① 觸發 → ② 聚焦 → ③ 宣告重點 → ④ 數據變化 → ⑤ 案例翻牌 → ⑥ 文字說明。前一段結束才開始下一段。禁止同時亮起、跳數字、翻卡、換字。

目前引擎（v3）的實際節奏：光柱與上方主題卡同時出現 → 主題卡約 2 秒後淡出 → 右側欄出現主標與簡介，數據此時才開始跳動 → 使用者故事翻牌，停約 2.6 秒後縮小飛進右側欄最後並自動捲到底。按「下一步」會直接呈現完成狀態。點分類標籤＝聚焦該區；點島上的項目直接進入該項目的說明，不另開視窗。
3. **三層深度。** 全景（一句標語）／導覽（自動播放，可暫停、跳步、調速）／細節（點開資訊卡：亮點、數據、簡介、沿革、資源）。沒內容的欄位整段隱藏，不留「暫無資料」。
4. **世界活著但不搶戲。** 8–12 項慢、小、低彩度的動態，且都和內容有關；拉近時會擋到內容的自動淡出。
5. **資訊誠實。** 數據附來源與年份；查不到就隱藏；第一手紀錄優先於二手整理。

## 視覺

柔和、低彩度、低多邊形的微縮模型，像木製桌遊或建築模型；立體但不寫實，平面著色；色彩只用來識別。

禁止：粗黑邊框、厚重按鈕陰影、大面積高彩度標籤、跟著物件跑的小頭像、emoji 當圖示、同時在動的多個資訊區塊。

色彩：ink #25313b、muted #6f7c87、faint #a3adb5、accent #c8643b（全站唯一強調色）；背景天空漸層 #c9e2ea→#e3eee9→#efece3；水 #8fc6cc、沙 #eadcbc、草 #b5d39a、樹 #7fae6e／#6c9e62／#94bd7f、建築牆面 #f7f2e8、屋頂＝類別識別色。有品牌色就從它延伸柔和版，不另外配色。

字型：標題 Noto Serif TC 700–900、字距 .04–.06em；內文 Noto Sans TC 400–500、13.5–15px、行高 1.85；小標 11px 粗體字距 .14em；數字用 tabular-nums。（離線檔內以系統字型回退，不連外載入。）

元件：毛玻璃面板（圓角 18px、柔和陰影、無邊框）；場景標籤（一般：半透明白底＋類別色點；目前焦點：深底白字）；宣告卡；翻牌卡；資訊卡。

## 目前的場景：小島

每個分類一座六角形島，大小與間距一致（蜂巢式排列，相鄰的島距離都相同）；島上放該分類的建築。每座島有自己的地面（紅磚、草地、木地板）和邊界（綠籬、木柵欄、原樣、混搭），島間道路各半段沿用兩端島的路面。人物比一般微縮模型大，有頭、軀幹與手腳，走、跑或騎腳踏車，髮型與隨身物（書包、側背包、書、咖啡）各不同；貓與鴿子少量點綴。人與動物都貼著地面行走，不飄在空中。

## 場景：大樓（`tower`）

玻璃帷幕大樓坐落在有厚度的廣場基座上（磁磚鋪面、外圍紅磚人行道、草地、低面數樹、路燈、長椅、入口雨遮、外梯），白天背景是淡藍漸層天空，夜晚是深色城市剪影。每層有白色樓板帶、玻璃帷幕（帶天空反射）與細竪框，部分樓層有陽台與白色實牆，屋頂有梯間、空調箱、屋頂花園與太陽能板；柔和陰影。配色低彩度：只取分類色的色相做樓層標籤與椅子等小地方，螢幕統一冰藍色。

每個分類一層樓（樓面 40×26），每個項目一間房；房間種類依項目名稱判斷（網路、資安→機房；諮詢、窗口、小幫手→服務台；申請、表單、文件→文件室；課程、教學、會議→會議室；數據、統計、報表→數據教室；系統、平台、帳號→辦公區），比對不到就依序輪流，同一層不重複。3 間以內排在後半層、前半層是開放區（每層不同：大廳沙發、咖啡吧、共享長桌、室內花園，加沿窗植栽與電話亭）；4–6 間分前後兩排，中間走廊；梯廳在走廊左端。家具約為一般比例的 1.45 倍，參考低面數辦公室模型的比例。

全景時每層一個「nF＋名稱」標籤，用指引線從大樓右側拉到外側一欄，可點；滑過時該層樓板光帶變亮。從全景進到某層：鏡頭先飛到該層玻璃外、慢慢穿過玻璃、再升到斜俯視的樓層平面，同時上方樓層與屋頂往上升起移開、該層玻璃淡出。全景只能點樓層；在某層時點房間（整間房都是點選範圍）就進該項目的演出。手機可上下撥動切換樓層。所有家具、竪框、樹都用 instancing（蓋章）畫，約 90 次繪製呼叫（含陰影）。

## 場景：市集（`market`）

low poly 風格的文創市集：紅磚圍牆與鐵門圍起的紅磚廣場，中央一條石板步道從大門通到後方三山牆的老紅磚倉庫主館；主館前有四台餐車與兩棵種在八角形花台裡的大榕樹，兩側是紅磚廠房，牆外有樹籬與行道樹。白天背景是淡藍偏暖的漸層天空，夜晚帳篷之間與步道上方亮起串燈、主館與廠房窗戶透出暖光。

每個分類一區白色帳篷：項目 3 個以內排一排（不足 3 頂補裝飾帳篷，點了會進到該區），4–6 個排兩排；左右兩側沿步道排列。每個項目一頂帳篷（攤位），帳篷垂邊有一條低彩度的分類色帶；攤上商品依項目名稱判斷（系統、網路、平台→科技小物與螢幕；諮詢、服務、申請→服務桌；教學、課程→書攤；文件、表單→卡片明信片；環境、永續→植物；設計、藝術→畫作；文創、周邊→帆布袋；咖啡、飲食→咖啡攤；其他依序輪流）。

人潮：每個攤位有攤主、攤前有一兩位在看的人，步道與各區走道上有沿路線來回走的人（腿以髖為軸、手以肩為軸反向擺動），餐車前有人排隊；全部用 instancing 每幀更新。全景時每區上方有可點的分區標籤；點分區鏡頭斜看整區；進到某個攤位時，鏡頭先拉近、最後才降下來轉成平視（站在攤前走道、略往中央步道側），攤前的人會往兩側讓開，擋在鏡頭與攤位之間的人暫時隱身，光柱在平視時淡出只留地上光圈（減少動態時直接到位）。

## 日夜主題與音效

依電腦時間自動切換白天（06:00–18:00）與夜晚。小島：白天晴空海灣、夜晚黃昏天燈；有海面、雲、鳥、帆船、天燈，光柱為漸層發光柱加地面光圈與閃粉。音效全部由程式即時合成（沒有音檔）：按鈕、點島、光柱、翻卡等操作音；全景時有淡淡的水聲、風聲與鳥鳴（夜晚蟲鳴；大樓是車輛由一側開到另一側的車行聲加零星人聲；市集是人群嘈雜聲加鳥鳴），導覽中靜音；音效預設關閉，點喇叭鈕才開。支援減少動態設定。

## 關於本站與下載檔名

三個版型的開場卡，導言最後都有一個 info 圖示；點了開「關於本站」視窗：「本站使用「NCCU 3D導覽網站小幫手」創建，帶大家走進{標題}的小世界。」並附小幫手的 GitHub Pages 連結（引擎裡的 `HELPER_URL`）。小幫手按「下載我的導覽網站」時，檔名是「標題_導覽網站_版型名.html」（版型名：小島、大樓、市集）。

## 版面與互動

桌機：左上標題與章節切換；右側唯一直立面板（摘要數據／本步說明／播放控制）；中央只放短暫演出；焦點移到面板以外的可視區中央。手機：面板變底部抽屜。

讀者可拖曳縮放，一拖曳就讓出自動運鏡；演出中按「下一步」直接跳到完成狀態；1×／2× 速度，停留時間依文字長度；點任何元素開資訊卡並暫停；鍵盤 ← → 換步、空白播放、Esc 關閉；結尾有收束畫面（結語＋總覽＋再看一次／回到全景）。

## 效能（v4）

小物件（樹、圍籬、人物零件等）改用 instancing，同一場景的繪製呼叫從約 688 降到約 89，三角形數量幾乎不變，手機更順。

## 項目多的島（v4.1）

一座島有 4 個以上項目時：每棟建築的造型改依「項目名稱」比對關鍵字（規則同分類造型），比對不到就從造型庫輪流取，讓同一島的建築長得不一樣；建築主體高度依位置錯落（後排高、前排矮、相鄰的高低不同，約 0.7–1.4 倍），讓後排不被前排遮住、標籤也能上下錯開；全景只顯示該島的分類名，點進該區才顯示各建築名稱；聚焦該島時鏡頭多退一些，避免被標題卡與右側面板蓋住。3 個以下的島外觀與 v4 完全相同。上限 6 個，超過建議拆成兩個分類（引擎仍會在內圈多放，但會擠）。
